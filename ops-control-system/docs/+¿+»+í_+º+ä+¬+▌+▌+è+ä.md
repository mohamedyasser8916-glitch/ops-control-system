# دليل التشغيل (للي مش مبرمج)

الدليل ده هيوصفلك خطوة بخطوة إزاي تشغّل نظام Operations Control System على جهازك عشان تجربه، من غير ما تحتاج خبرة برمجة.

## قبل ما نبدأ: هنستخدم إيه؟

1. **Node.js** — البرنامج اللي بيشغّل تطبيق الويب. مجاني.
2. **Docker Desktop** — بيشغّللك قاعدة بيانات PostgreSQL على جهازك من غير ما تتعب في تنصيبها يدوي. مجاني.

## الخطوة 1: تنصيب البرامج المطلوبة

### على ويندوز أو ماك:

1. حمّل ونصّب **Node.js** (النسخة LTS) من: https://nodejs.org
2. حمّل ونصّب **Docker Desktop** من: https://www.docker.com/products/docker-desktop
   - بعد التنصيب، شغّل Docker Desktop وسيبه شغال في الخلفية (هتلاقي أيقونته في شريط المهام).

## الخطوة 2: افتح "سطر الأوامر" (Terminal)

- **ويندوز**: افتح قائمة ابدأ واكتب `PowerShell` وافتحه.
- **ماك**: افتح "Terminal" من Applications > Utilities.

## الخطوة 3: روح لمجلد المشروع

اكتب الأمر ده (غيّر المسار حسب مكان المجلد عندك):

```
cd path\to\ops-control-system
```

## الخطوة 4: جهّز ملف الإعدادات

انسخ ملف `.env.example` وسمّي النسخة `.env`. تقدر تعمل ده بالأمر:

**ويندوز (PowerShell):**
```
copy .env.example .env
```

**ماك:**
```
cp .env.example .env
```

بعدين افتح ملف `.env` بأي برنامج نصوص (Notepad مثلاً) وغيّر السطر ده لقيمة عشوائية طويلة (ده مفتاح أمان داخلي، مش لازم تفتكره):

```
NEXTAUTH_SECRET="ضع هنا نص عشوائي طويل"
```

تقدر تولّد نص عشوائي بالأمر ده في PowerShell:
```
[Convert]::ToBase64String((1..32 | %{Get-Random -Max 256}))
```

## الخطوة 5: شغّل قاعدة البيانات

```
docker compose up -d db
```

هتستنى شوية (أول مرة بس) وهتشوف رسالة إن الحاوية اشتغلت.

## الخطوة 6: نصّب مكتبات المشروع

```
npm install
```

الأمر ده بيحمّل كل المكتبات اللي التطبيق محتاجها. أول مرة بياخد كام دقيقة.

## الخطوة 7: جهّز قاعدة البيانات وحمّل البيانات

```
npm run db:migrate
npm run db:seed
```

الأمر الأول بيبني جداول قاعدة البيانات. التاني بيعمل حساب "Admin" أول مرة، وبيحمّل بيانات العينة الحقيقية من ملف الإكسل اللي بعتّه (مش بيانات وهمية).

هتلاقي في الآخر رسالة زي:
```
Created Admin user: admin@example.com
Seed complete.
```

**احتفظ بالإيميل والباسورد اللي حطيتهم في ملف .env** — هتستخدمهم لتسجيل الدخول.

## الخطوة 8: شغّل التطبيق

```
npm run dev
```

هتشوف رسالة فيها `http://localhost:3000` — افتح اللينك ده في المتصفح (Chrome مثلاً).

## الخطوة 9: سجّل دخول

استخدم الإيميل والباسورد اللي حطيتهم في ملف `.env` (`SEED_ADMIN_EMAIL` و`SEED_ADMIN_PASSWORD`).

---

## علامات إن كل حاجة شغالة صح

- لما تفتح `http://localhost:3000` تشوف شاشة تسجيل الدخول (خلفية كحلي).
- بعد تسجيل الدخول، هتلاقي في القائمة الجانبية: Agent Custody Search, Warehouse POS, Warehouse Materials, Data Management.
- لو دخلت على Agent Custody Search وكتبت اسم أو كود أي موظف من الـ 71 موظف الموجودين في بيانات العينة، المفروض تشوف بياناته.

## لو حصلت مشكلة

- **رسالة "port already in use"**: يبقى في برنامج تاني شغال على نفس البورت (3000 أو 5432). قفل البرنامج ده أو غيّر البورت في `docker-compose.yml`.
- **Docker مش شغال**: افتح تطبيق Docker Desktop وسيبه يفتح تمام الأول.
- أي مشكلة تانية، ابعتلي رسالة الخطأ بالكامل وهساعدك أوصلها.

## إزاي توقف التطبيق

في نافذة الـ Terminal اللي شغال فيها `npm run dev`، اضغط `Ctrl + C`.

عشان توقف قاعدة البيانات: `docker compose down` (البيانات بتفضل محفوظة، مش بتتمسح).
